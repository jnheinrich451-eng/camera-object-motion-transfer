# Camera & Object Motion Transfer — results page

The project page of the honours thesis *Camera & Object Motion Transfer with a Frozen Video Model* (John Zeng, Australian National
University, 2026; supervisor Dr Jing Zhang). It shows, per reference clip and target, the reference, the baselines and our result, the
measured table and the limitations. Served by GitHub Pages from this repository's root: `index.html`, `videos/`, `figures/`.

The page is generated, not edited by hand: `scripts/make_results_page.py` in the code repository renders it from the batch export and the
baseline folders. Code: https://github.com/jnheinrich451-eng/mixture-motion-transfer
